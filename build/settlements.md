# Места Ромашковой долины

Места отсылают к сериям «Смешариков». Названия отдельных районов, огородов, победные очки и координаты — адаптация для мода, а не утверждение о канонических городах. По просьбе пользователя включены исключения из нового 2D сезона и почта из «Новых приключений». С.К.А.М.Е.Й.К.А сохраняет выбранное пользователем написание. Природные ориентиры имеют 0 VP; огороды сохраняют сельский ландшафт. Столицы имеют 10 VP.
